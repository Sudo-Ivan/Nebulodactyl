NEBULODACTYL

A game server management panel forked from Hydrodactyl, with a space theme and support for joining nodes over a Nebula overlay network.

View on GitHub Installation guide

What you get

Space theme

A nebula-inspired color scheme with deep-space backgrounds, starfield accents, and a violet/cyan palette.

Nebula overlay

Run panel-to-node traffic over a mutually authenticated Nebula overlay instead of exposing daemons publicly.

Client panel

Console, files, databases, backups, network, users, startup, schedules, activity, and software in one interface.

Marketplace

Native plugin and mod installer for Minecraft servers backed by Modrinth, Hangar, and Spiget.

S3 backups

Per-node backup storage with any S3-compatible provider.

Signed artifacts

Images and releases ship with Cosign keyless signatures, SBOMs, SLSA provenance, and OpenVEX documents.

Your database

MySQL, MariaDB, or PostgreSQL. Pick what you already run.

Modern stack

Laravel 13, React 19, TypeScript, and Tailwind CSS, formatted and linted with Biome.

Nebula overlay networking

Nebula is a mutually authenticated, peer-to-peer overlay network originally built at Slack. Nebulodactyl nodes can join the same overlay, so the panel reaches each daemon over encrypted tunnels pinned to host certificates. Lighthouses handle discovery and NAT traversal, and group-based firewall rules keep node ports closed to anything outside your fleet.

Configuration lives in config/nebula.php, with a full host example in examples/nebula/config.example.yml.

Quick start

git clone https://github.com/Sudo-Ivan/Nebulodactyl.git
cd Nebulodactyl
cp .env.example .env
cp docker-compose.example.yml docker-compose.yml
docker compose up -d
