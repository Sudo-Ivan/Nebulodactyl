A game server management panel forked from Hydrodactyl, with a monochrome space theme and first-class Nebula overlay networking.

What you get

Nebula overlay

The panel signs node certificates and routes daemon traffic over a mutually authenticated Nebula mesh. Nodes enroll themselves with the nebulod agent.

nebulod agent

A small Go daemon on each node: enrolls with the panel, renders the nebula config, supervises the tunnel, and serves health and metrics on the overlay.

Space theme

Monochrome void palette with a twinkling starfield and ambient glow, matching the quad4.io aesthetic.

Client panel

Console, files, databases, backups, network, users, startup, schedules, activity, and software in one interface.

Marketplace

Native plugin and mod installer for Minecraft servers backed by Modrinth, Hangar, and Spiget.

Runs anywhere

Behind Coolify, Traefik, nginx, or Caddy with trusted proxy support and a health endpoint built in.

Your database

MySQL, MariaDB, PostgreSQL, or SQLite for small self-hosted installs.

Signed artifacts

Images and releases ship with Cosign keyless signatures, SBOMs, SLSA provenance, and OpenVEX documents.

Nebula overlay networking

Nebula is a mutually authenticated, peer-to-peer overlay network originally built at Slack. The panel acts as the certificate authority: each node enrolls once with its daemon token, receives a signed certificate and an allocated overlay address, and the panel then prefers the overlay IP for all daemon traffic. Lighthouses handle discovery and NAT traversal, and group-based firewall rules keep node ports closed to anything outside your fleet.

Panel config lives in config/nebula.php. Initialize the CA with php artisan nebula:init-ca, then run agent/nebulod on each node.

Quick start

git clone https://github.com/Sudo-Ivan/Nebulodactyl.git
cd Nebulodactyl
cp .env.example .env
docker compose up -d
Pre-release software under active development. Review the upstream Hydrodactyl docs before installing. See examples/coolify/ for a reverse proxy deployment.
